# Detailed Implementation Plan - Milestone 7: E2E Testing & Hardening

This plan outlines the detailed steps to complete Milestone 7 of the Daystar project.

## Tasks

### 1. E2E Testing
- **Create `tests/test_e2e.py`**:
    - **Test Case 1: Full Mocked Lifecycle**:
        - Simulate a full 15-minute lifecycle (compressed in time).
        - Verify that `process_tick` calls the prober with the expected steps at the right simulated times.
        - Verify that the database state is updated correctly at each step.
    - **Test Case 2: Safety Limit Intervention**:
        - Simulate reaching the safety limit of concurrent clusters.
        - Verify that `process_tick` triggers cleanup (truncating database and deleting mock resources).
- **Tooling**: Use `pytest` and `monkeypatch` to mock time and `MockProber`.

### 2. Database Optimization
- **Analyze current usage**: `get_active_clusters()` returns all data including large logs.
- **Proposed Change**:
    - Add a new endpoint `/status/summary` or modify `/status` to return a summarized view (without logs) for the main grid rendering.
    - Keep or add an endpoint for detailed view on hover if needed, or rely on the full data if performance is acceptable.
    - Given the expected small number of clusters, we will first measure performance before optimizing.

### 3. Performance Telemetry
- **Add telemetry**:
    - In `backend/manager.py`, measure time taken by `process_tick`.
    - Log execution time and log a warning if it takes too long (e.g., more than a few seconds).
    - Expose this telemetry if needed, or just log it.

### 4. Dockerization
- **Choice**: Run both FastAPI and Manager in the same container to simplify deployment and avoid TinyDB locking issues.
- **Implementation**:
    - Update `backend/main.py` to start the `main_loop` from `manager.py` as a background task on startup.
    - Create `Dockerfile` in the project root:
        - Base image: `python:3.11-slim`.
        - Install dependencies from `requirements.txt`.
        - Copy source code.
        - Command: `uvicorn backend.main:app --host 0.0.0.0 --port 8000`.

### 5. K8s Manifests
- Create `k8s` directory.
- **`k8s/deployment.yaml`**:
    - Define a Deployment for the Daystar application.
    - Use the Docker image built in step 4.
    - Mount a volume for persistent data if TinyDB needs to persist across pod restarts (otherwise it will be wiped, which might be acceptable for a prober).
- **`k8s/service.yaml`**:
    - Expose the FastAPI app via a LoadBalancer or NodePort.

### 6. Security Review
- **Subprocess calls in `gke_prober.py`**:
    - `gcloud container clusters get-credentials`
    - `kubectl apply`
    - `kubectl get svc`
- **Review**: Since arguments are passed as a list and not a shell string, shell injection is prevented. We should ensure input parameters like cluster names are validated or sanitized if they come from user input (currently they are generated by the system).

### 7. Documentation
- Update `README.md` with:
    - How to run tests.
    - How to build and run the Docker container.
    - How to deploy to K8s.

## Verification
- Run `pytest` to verify all tests pass.
- Build Docker image and run it locally to verify it starts and serves the UI.
